# Simple Terminal Chatbot

A basic command-line chatbot using OpenAI's GPT-3.5-turbo.

## Setup

1. Clone the repo:
   ```
   gh repo clone RajsekharPal7/Simple_Chatbot
   cd Simple_Chatbot
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

3. Create a `.env` file  and add your real OpenAI API key:
   ```
   OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx
   ```

4. Run the chatbot:
   ```
   python chatbot.py
   ```

5. Type `exit` or `stop` to quit.
